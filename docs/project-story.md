# Engram-Memory · 项目故事

> 口径：以下分数都是**当前这套记忆系统**（抽取器四表 + bi-temporal/supersession 折叠 + 混合检索 + Self-Ask 多跳迭代）测得的。迭代早期的分数一律不计。

## 一、项目与作者

- **项目名**：Engram-Memory（Engram = 记忆痕迹，神经科学里记忆在大脑中的物理印迹）。
- **作者**：21 岁，一本中医学大三学生，**非计算机/AI 专业背景**。
- **时间线**：
  - 2026-10-14 开始研究 API；
  - 2026-10-22 专攻 agent 长期记忆；
  - 2026-11-18 单跳 262k 稳定 **93%**；
  - 2026-11-19 多跳 262k 稳定 **25%**（gpt-4o-mini）/ **48%**（deepseek-flash，思考关闭）。
- **开发/运行环境**：**无独显轻薄本**——13 代 Intel i5-13420H + 16GB 内存，Windows 11。全部开发、抽取、检索、测评都在这台机器上稳定运行（无需 GPU、无需大内存）。

## 二、它是什么

一个**面向 AI Agent 的长期记忆系统**：把对话/长文自动抽成四类结构化事实（断言 / 事件 / 指标 / 身份），带时间与取代链（冲突消解），检索时折叠取最新，喂给任意 LLM 作答。解决的是「长上下文里记忆冲突、取旧值、多跳推理失准」这类问题。

## 三、成绩（权威基准 MemoryAgentBench · Conflict_Resolution）

| 任务 | Engram-Memory | 论文/基线对照 |
|---|---|---|
| 单跳 262k（substring） | **93.2%**（5 次均值） | GPT-4o 60 · BM25 56 · gpt-4o-mini 45 |
| 单跳 6k | **98%** | — |
| 多跳 262k（substring） | **48.3%**（deepseek 作答，3 次均值） | 论文多跳全部 ≤6% |
| 多跳 262k（gpt-4o-mini 作答） | **25.3%**（3 次均值） | — |
| 多跳 262k 纯直接对照 | 5.3%（deepseek 直接读全文，不用记忆） | — 记忆系统 +43pp |
| 多跳 6k | **65%** | — |
| 中文 LoCoMo 全量 | 272 会话 **98.9%** 过 | — |

关键对比：**单跳 262k 从「直接 64%」拉到 93%（+29pp）；多跳 262k 从「直接 5.3%」拉到 48%（+43pp）**——长上下文多跳，纯直接几乎全军覆没，记忆系统是决定性贡献。

## 四、架构（四个环节）

1. **抽取器**：长文/对话 → 四表（facts 断言「X 是 Y」· cards 事件「发生了什么」· metrics 指标 · identities 身份），LLM 抽取 + 确定性校验 + 引文必须是原文子串。
2. **取代链（supersession）**：同一主体多版本时按序号取最新，旧值 invalidated——这就是「冲突消解」，比 RAG 的「检索拼块」多一层「谁新谁旧」的语义。
3. **检索**：多字段 BM25 + 向量（all-MiniLM-L6-v2）+ RRF 融合；整库向量只建一次缓存（实测检索提速 ~1340×）。
4. **多跳迭代**：Self-Ask 式——把多跳题拆成单跳子问题，逐跳检索、拼证据链、再终答（`OUR_SYSTEM_ITERATIVE` 可开关，默认单跳）。

## 五、成本（一次 262k 完整测评，实测/估算）

- **抽取**：1.1M 字符长文 → 67 块 → 870 片，8 并发约 **11.5 分钟**（DeepSeek-flash）。
- **作答**：100 题单跳约 **4 分钟**；100 题多跳约 **15~25 分钟**。
- **token**：抽取约 300 万输入 token；作答 100 题约 70 万输入 token。
- 全部本地/国产可跑（DeepSeek 国内直连，无境外依赖）。

## 六、开源动机

不是求名、不是求财——是「支出转收入」：用开源换**继续开发的资源**（算力、协作、反馈）。钱财与名声只是可能的副产物。技术本身的卖点是「非专业背景做到这程度的方法」，数据安全优先、不喂训练数据公司。

## 七、产品方向

- **本地模型高水平记忆**：记忆系统负责「抽取 + 折叠 + 检索」，作答模型只负责「照检索到的证据作答」，本地小模型也能达到云端级记忆准确度——模型智力不再成为「准确记忆」的门槛。
- **高隐私部署形态**：一台本地高配置服务器（本地部署大模型，负责抽取）+ 多个低配置检索端（负责检索/作答）——低成本、高隐私、高准确、高速度召回。
- **证据**：262k 单跳连测 5 次均值 **93.2%**（substring）；其中本地 Qwen 7B 作答 **92%**，与云端 gpt-4o-mini / deepseek 的 92-93 持平；直接长文只有 64%。

## 附：系统组件与术语

- **许可证**：Apache-2.0。
- **四表数据模型**（抽取器的输出）：
  - `facts` 断言——「X 是 Y」的陈述性事实（如 "the capital of X is Y"）。
  - `cards` 事件——「发生了什么」的过程记录。
  - `metrics` 指标——带数值/单位的度量。
  - `identities` 身份——实体是谁。
- **supersession（取代链）**：同一主体的多个版本，按序号取最新，旧值 `invalidated_at` 标记作废；`fold` 折叠时只保留最新。这是「冲突消解」的核心，区别于普通 RAG 的「无差别拼块」。
- **四个环节的模块名**：Extractor（抽取器）· Supersession/fold（取代链与折叠）· Retriever（检索器）· Iterative answerer（多跳迭代作答）。
